# Public Source Policy

This repository is intended to be public and educational.

## Suitable for the public repository
- Original explanations, derivations, solutions, algorithms and code created for this project.
- Structured source metadata and bibliographic citations.
- Original figures, SVGs and visualizations created from verified study data.
- Question/source provenance such as institution, exam year, page and question number.

## Keep outside the public repository by default
- Full copyrighted textbooks or solution manuals.
- Full teacher-note scans unless redistribution permission is explicit.
- Large copied chapters or wholesale transcriptions from copyrighted books.
- Private Google Drive URLs, credentials, tokens or personal data.
- Raw source scans not explicitly approved for redistribution.

The original source files can stay in private/cloud storage while GitHub stores source IDs,
citations, page/question references and this project's own structured learning content.
