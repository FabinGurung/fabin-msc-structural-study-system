# Bootstrap Upload Note

This archive is designed for the existing GitHub repository root.

1. Extract the ZIP on your computer.
2. Upload the extracted CONTENTS, not the ZIP itself.
3. Do not upload the enclosing local folder as a new folder in GitHub.
4. README.md is intentionally omitted so the repository's existing README is not overwritten.
5. The package contains no source PDFs, textbooks, teacher scans, credentials or private Drive URLs.
