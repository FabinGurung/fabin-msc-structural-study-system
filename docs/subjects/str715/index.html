Final Internal Examination — Q1
Qualitative methodsRVSChecklist screening
1

Explain any two qualitative methods for seismic evaluation of structures.

10 marks
1 · DefineWhat qualitative evaluation does
2 · Method ARapid Visual Screening
3 · Method BChecklist / empirical vulnerability review
4 · CloseUse result to prioritize detailed analysis
Source anchorThe STR 715 outline explicitly includes Qualitative Methods under Seismic Assessment. The supplied answer book contains Rapid Visual Screening and a more detailed empirical/checklist-style assessment discussion.

Qualitative seismic evaluation assesses likely earthquake vulnerability mainly from observable building characteristics, configuration, condition and past-performance indicators, before or instead of a complete numerical model.

A. Rapid Visual Screening (RVS)

  • Quick field screening by a trained evaluator.
  • Identify structural system, storey count and apparent construction quality.
  • Observe soft/weak storey, setbacks, re-entrant corners, torsional irregularity and short columns.
  • Record visible cracks, deterioration, pounding risk, heavy parapets/appendages and obvious site concerns.
  • Convert observations into a screening score / vulnerability class.

Use: prioritization of buildings needing detailed evaluation.

B. Checklist / empirical vulnerability assessment

  • Uses a structured checklist, expert judgement and lessons from earthquake damage.
  • Checks load path, wall/diaphragm connection, irregularity, deterioration, material quality and detailing.
  • Each deficiency may receive a class, score or weight.
  • Combined result gives a relative vulnerability ranking.

Use: building-stock screening when drawings or exact material data are limited.

Figure to remember Qualitative screening → vulnerability class → detailed analysis when triggered.

Exam-ready close

Thus, qualitative methods do not attempt to calculate exact nonlinear capacity. Their principal purpose is to identify vulnerable features quickly, rank risk, and decide where detailed analytical assessment should be concentrated.

Final Internal Examination — Q2
Analytical methodsPushoverInelastic time history
2

Discuss any two analytical methods adopted for performance assessment of structures.

10 marks
Source discrepancy — do not memorize blindlyThe handwritten answer book lists pushover curve analysis and fragility curve analysis. The official STR 715 outline, however, places fragility curves under Vulnerability Assessment and lists Capacity/Demand Method, Pushover Analysis and Inelastic Time History Analysis as analytical seismic-assessment methods. For an exam answer aligned to the syllabus, the pair below is safer.

A. Nonlinear static pushover analysis

  1. Create a structural model and apply gravity loads.
  2. Assign nonlinear behaviour / hinge properties.
  3. Apply a selected lateral-load pattern.
  4. Increase lateral load step by step.
  5. Track base shear, roof displacement, storey drift and hinge sequence.
  6. Plot the capacity curve: Vb versus Δroof.
  7. Compare with demand / target displacement to judge performance.

Strength: shows yielding sequence, weak storeys and approximate nonlinear capacity with moderate computational effort.

B. Inelastic time-history analysis

  1. Use a nonlinear structural model.
  2. Select ground-motion records compatible with the hazard scenario.
  3. Apply earthquake acceleration as a function of time.
  4. Solve structural response increment-by-increment.
  5. Extract displacement, drift, force, acceleration and nonlinear deformation histories.
  6. Compare peak / residual demands with performance limits.

Strength: retains the time sequence, repeated yielding and dynamic effects that a static method cannot reproduce directly.

Conceptual dynamic equilibrium: M·ü(t) + C·u̇(t) + R[u(t)] = −M·r·ag(t)
Syllabus-aligned pair Pushover shows a nonlinear capacity path; inelastic time history resolves dynamic response through time.

One-line comparison

Pushover is simpler and highly useful for global capacity / mechanism insight; inelastic time-history is more demanding but can represent dynamic response, higher-mode contribution and repeated nonlinear cycles more directly.

Final Internal Examination — Q3
DCRDemand-to-capacity ratio
3

Define DCR. What parameters are considered for assessment with DCR? Explain in details.

10 marks

DCR = Demand-to-Capacity Ratio. It expresses the size of the action demanded by the earthquake/load combination relative to the corresponding component capacity.

DCR = QUD / QCE QUD = demand (force/action) QCE = expected/reference capacity

Demand-side inputs

  • Dead and superimposed dead load.
  • Applicable live load.
  • Earthquake action and analysis direction.
  • Action checked: P, V, M, T or interaction.
  • Mass, stiffness, period / modal response where required.
  • Load combination and torsional effects specified by the adopted evaluation procedure.

Capacity-side inputs

  • Concrete, steel or masonry strength.
  • Member dimensions / section geometry.
  • Longitudinal reinforcement, ties/stirrups, anchorage and confinement.
  • Axial load level.
  • Cracking, corrosion, section loss, deterioration and previous damage.
  • Expected component strength for the action being checked.
DCR resultMeaning for quick interpretation
DCR < 1Demand is below the selected reference capacity.
DCR ≈ 1Demand is approximately at the selected reference capacity.
DCR > 1Demand exceeds that reference capacity; acceptance / performance must be examined using the adopted procedure.
Memory hook DCR asks only one question: How large is demand compared with capacity?
Acceptance cautionThe supplied study material uses the simple DCR interpretation above. Exact pass/fail acceptance limits can depend on the specific evaluation standard and action type; therefore do not claim that every DCR above 1 automatically means structural collapse.
Final Internal Examination — Q4
Capacity vs demandADRSPerformance point
4

How the seismic capacity and demand of the structure is assessed? Explain in details.

10 marks
CapacityPushover curve
TransformSa–Sd / ADRS
DemandResponse spectrum
ComparePerformance point

1. Structural capacity

  1. Model the existing structure using geometry, member stiffness and available material information.
  2. Apply gravity loads and a selected lateral-load pattern.
  3. Increase lateral action progressively.
  4. Record base shear Vb and roof/control displacement Δ.
  5. Plot the capacity curve and identify stiffness change, yielding, strength and post-yield response.
  6. For a capacity-spectrum procedure, transform the pushover curve into spectral acceleration Sa versus spectral displacement Sd.

2. Seismic demand

Demand is represented from the selected earthquake hazard, commonly through a response spectrum or earthquake time-history records. In a capacity-spectrum method, the demand spectrum is expressed in the same Sa–Sd coordinate system as the capacity spectrum.

3. Capacity–demand comparison

The compatible intersection gives an estimate of the expected maximum response, called the performance point. At or near it, check roof/spectral displacement, base shear/spectral acceleration, storey drift, hinge state and component demand against performance limits.

Core exam figure Plot capacity and demand in the same spectral coordinate system; their compatible intersection is the performance point.

Essential principle

Seismic assessment = Capacity versus Demand at the selected hazard level. The method may be linear, nonlinear static or nonlinear dynamic, but the decision still depends on comparing earthquake-induced demand with the structure's available strength/deformation capacity.

Final Internal Examination — Q5
Performance pointIO/LS/CP
5

What is performance point? Explain the globally adopted performance criteria to assess the building performance with relevant figure.

10 marks

Performance point is the compatible point at which the capacity spectrum and demand spectrum meet in a capacity-spectrum assessment. It represents an estimate of the structure's maximum response for the considered earthquake demand.

Information read / derived at the point

  • Spectral displacement and corresponding roof displacement.
  • Spectral acceleration and associated base shear.
  • Expected storey drift.
  • Plastic-hinge / component deformation state.
  • Whether the target performance objective is satisfied.

Performance criteria to remember

  • IO — Immediate Occupancy: limited damage; major strength and stiffness largely retained.
  • LS — Life Safety: significant damage, but a margin against collapse remains.
  • CP — Collapse Prevention: severe damage, very small remaining margin, but global collapse is intended to be prevented.
Course-note wordingThe supplied answer material also uses an intermediate Moderate Damage / Damage Control region between IO and LS. Terminology varies by framework. In the exam, label the levels clearly and explain the damage progression instead of treating one naming convention as universal.
Figure to reproduce As displacement demand moves right, damage progresses from IO toward LS and CP. The performance point must be judged against the target level.
LevelExam phraseWhat it means
IOLimited damageBuilding retains substantial strength/stiffness and can generally return to use after inspection and limited repair, subject to nonstructural/utility condition.
LSSignificant but survivable damageDamage is substantial; life-threatening hazards are controlled and a margin against collapse remains.
CPNear-collapse conditionSevere damage with little residual margin, but global collapse is intended to be prevented.

Exam-ready conclusion

A building satisfies the selected objective when the response at the performance point remains within the deformation, drift and component limits associated with the target performance level for the chosen earthquake hazard.

Final Internal Examination — Q6
Bilinear idealizationCapacity curveDuctility
6

Write down the detailed procedure for bilinear idealization of capacity curve. Explain its importance.

10 marks
1 · StartNonlinear pushover curve
2 · IdealizeElastic + post-yield lines
3 · ExtractVy, Δy, Vu, Δu, μ
4 · UsePerformance / demand comparison
Source anchorThe supplied answer book defines the capacity curve as the structure’s force–displacement response, explains elastic versus plastic response, and states that bilinear idealization is used for further analysis and for computing the performance point. The supplied “Pushover1.pdf” also constructs a bilinear curve using a yield point, an ultimate point and a post-yield stiffness.

Bilinear idealization replaces the irregular nonlinear pushover capacity curve by two straight-line segments: an initial elastic branch and a post-yield branch. The idealized curve preserves the key engineering information while making yield, ductility and performance calculations easier.

Step-by-step procedure

  1. Obtain the pushover capacity curve. Plot base shear \(V\) on the vertical axis against roof/control displacement \(\Delta\) on the horizontal axis.
  2. Identify the initial elastic region. Use the approximately linear early portion of the curve to define the initial lateral stiffness \(K_e\).
  3. Identify the yield transition. Select the point at which the response changes from predominantly elastic to inelastic. Denote it by the idealized yield point \((\Delta_y,V_y)\).
  4. Select the ultimate/control point. Use the chosen terminal performance point of the capacity curve—e.g. the point corresponding to the adopted ultimate or collapse-prevention displacement in the supplied pushover workflow—as \((\Delta_u,V_u)\).
  5. Draw the first branch. Connect the origin to the idealized yield point. Its slope is the effective elastic stiffness.
  6. Draw the second branch. Connect the yield point to the ultimate point using the post-yield slope \(K_p\). This branch represents reduced stiffness after yielding.
  7. Calculate key properties. From the idealized curve determine initial stiffness, post-yield stiffness, yield strength, ultimate strength and displacement ductility.
  8. Check that the idealization represents the original curve reasonably. The purpose is not to reproduce every local fluctuation; it is to retain the dominant elastic and inelastic response used in subsequent seismic-performance calculations.
Ke = Vy / Δy Kp = (Vu − Vy) / (Δu − Δy) Ductility, μ = Δu / Δy
Core figure Actual capacity curve is simplified into two branches so yield and post-yield behaviour are explicit.

Why it is important

  • Gives a clear yield point.
  • Separates elastic and inelastic behaviour.
  • Provides effective stiffness and post-yield stiffness.
  • Makes ductility calculation straightforward.

How it is used

  • Simplifies capacity-spectrum / performance-point calculations.
  • Supports comparison of capacity and seismic demand.
  • Makes different structures or retrofit alternatives easier to compare.
  • Reduces a complicated curve to exam-usable engineering parameters.
ClarificationThe scanned answer book does not provide a code-specific equal-area or FEMA/ATC iterative construction rule. Therefore this answer does not pretend that such a specific algorithm was present in the source. It uses the bilinear logic explicitly supported by the answer book and supplied pushover documentation.

Exam-ready conclusion

Bilinear idealization is important because it converts a complicated nonlinear capacity curve into a simple model defined mainly by yield strength, yield displacement, post-yield stiffness and ultimate displacement. These parameters are then directly usable in seismic-performance and demand–capacity assessment.

Final Internal Examination — Q7
Fragility curveDamage statesPGA/ISDR
7

Explain step by step procedure in details for derivation of fragility curve.

10 marks
1 · DefineDamage states
2 · MeasureIM + response parameter
3 · EstimateMedian μ + dispersion β
4 · PlotProbability of exceedance

A fragility curve gives the probability that a specified damage state is reached or exceeded for a given earthquake intensity measure.

P[DS ≥ ds | IM] = Φ { ln(IM / μds) / βds } μds = median intensity causing the damage-state threshold βds = logarithmic dispersion Φ = standard normal cumulative distribution function

Procedure from the supplied answer notes

  1. Define damage states. The answer book uses performance/damage labels such as Immediate Occupancy, Moderate Damage, Life Safety and Collapse Prevention.
  2. Select an intensity measure (IM). The notes use PGA as the example intensity measure.
  3. Select the structural response measure. Two routes are shown:
    • Roof-displacement method → SDOF-style response.
    • Inter-storey drift ratio (ISDR) → storey-by-storey / MDOF response.
  4. Run or assemble response data at several intensity levels. For each PGA level, obtain the corresponding response (roof displacement or ISDR).
  5. Compare responses with damage-state thresholds. Determine at which intensities each threshold is reached or exceeded.
  6. Build the data table. Arrange IM values against exceedance probability for each damage state.
  7. Estimate the median intensity \(\mu_{ds}\). The notes identify the median as the intensity at which the exceedance probability is about 50%.
  8. Estimate logarithmic dispersion \(\beta_{ds}\). This describes the spread/uncertainty of the damage-state transition.
  9. Evaluate the lognormal fragility expression. Compute \(P[DS\ge ds|IM]\) across the required IM range.
  10. Plot all damage-state curves. Horizontal axis = IM such as PGA; vertical axis = probability of exceedance from 0 to 1.
Memory hook Higher damage states shift to the right because larger earthquake intensity is generally required to reach them.
Source-specific detailThe handwritten notes explicitly show PGA–ISDR tables, roof-displacement and ISDR response routes, the median \(\mu\), logarithmic dispersion \(\beta\), and a family of fragility curves.

Exam-ready conclusion

Therefore, fragility derivation requires three linked ingredients: earthquake intensity, structural response/damage thresholds, and statistical uncertainty. The final curve converts these into the probability that each damage state will be exceeded at any selected intensity.

Final Internal Examination — Q9
Local retrofitGlobal retrofit
9

Explain the local and global level retrofitting methods in details.

10 marks

The central distinction is the scale of intervention.

LOCAL retrofit = member level

Targets a deficient beam, column, joint, wall segment or connection while retaining the overall structural system.

GLOBAL retrofit = structure level

Changes the behaviour of the whole building by modifying the lateral system, stiffness distribution or seismic demand.

A. Local-level methods

  1. Concrete jacketing / section enlargement. Additional reinforcement and concrete are placed around an existing member to increase capacity and confinement.
  2. Steel jacketing. Steel plates, angles or jackets are attached around a deficient member to improve local strength and ductility.
  3. FRP / CFRP wrapping. Composite sheets or bands are externally bonded around selected regions to enhance confinement and local capacity while adding little mass.
  4. Local connection or joint strengthening. Strengthening is concentrated at deficient joints, anchorage zones or member ends where load transfer is inadequate.

B. Global-level methods

  1. Addition of shear walls. New walls increase global lateral stiffness and strength and can reduce storey drift when placed and connected appropriately.
  2. Steel bracing. Diagonal bracing creates a stronger lateral-force-resisting path and changes the distribution of seismic forces.
  3. Base isolation. Isolation devices alter the dynamic characteristics of the building so that earthquake demand transferred to the superstructure is reduced.
  4. Supplemental damping / energy dissipation. Dampers reduce response by dissipating energy, where such a system is selected and designed.
Core distinction Local methods improve selected components; global methods modify the response of the building as a structural system.
Drive source confirmationThe STR 715 review paper already stored in Drive explicitly classifies local methods as member-level interventions and global methods as structure-level interventions. It lists concrete/steel/composite local methods and shear walls, steel bracing and base isolation as global methods.

Selection principle

Choose a local method when deficiencies are concentrated and the global structural concept remains adequate. Choose a global method when the building lacks sufficient overall lateral strength/stiffness, has excessive drift, or needs its seismic demand or load path changed. Hybrid combinations may be necessary.

Final Internal Examination — Q10
Post-Gorkha retrofitNepal masonryRC retrofit
10

Write down the detail retrofitting techniques applied after 2015 Gorkha earthquakes in Nepal for improving structural integrity of masonry and RC structures.

10 marks
Strongest post-Gorkha source in the Drive collectionThe Government of Nepal’s Seismic Retrofitting Guidelines of Buildings in Nepal, 2016 were prepared/approved in the post-Gorkha context and explicitly cover adobe/low-strength masonry, masonry and RCC. The guideline lists practical wall, diaphragm, roof, foundation, opening and crack-restoration measures for damaged/vulnerable buildings.
Evidence ruleThe handwritten answer book lists CFRP, jacketing, base isolation, bracing, batten/lacing and shear walls as techniques “applied after 2015”. The Drive literature does not prove that every one of these was widely implemented across Nepal. Therefore the answer below separates Government-guideline/post-Gorkha measures, a documented Shital Niwas case, and broader RC retrofit methods discussed in the STR 715 sources.

A. Masonry / low-strength masonry — post-Gorkha guideline measures

  1. Seismic bands / belts. Provide horizontal bands at critical levels to tie walls together and improve box action.
  2. Gable-wall bands and vertical reinforcing. Strengthen vulnerable gable ends and wall intersections against out-of-plane separation.
  3. Encasement / strengthening around openings. Reinforce door and window zones where cracking commonly concentrates.
  4. Wall jacketing / external reinforcement. The Nepal guideline includes polypropylene bands, bamboo reinforcement, cane/rope mesh, wire mesh, polymer mesh and other external strengthening options for low-strength masonry.
  5. Floor and roof diaphragm stiffening. Improve the connection and in-plane action of floors/roofs so lateral forces are distributed to walls rather than allowing independent wall movement.
  6. Foundation strengthening. Strengthen the support system where assessment shows inadequate stability or load transfer.
  7. Control of openings. Infill or strengthen excessive/poorly located openings and provide seismic belts around openings where required.
  8. Through-elements / bond elements. Improve connection through thick stone masonry and across wall thickness where needed.
  9. Damage restoration. Use grouting for suitable cracks/voids and seal fine cracks; locally dismantle and rebuild unsafe masonry when repair alone is inadequate.
Guideline concept The central objective is to tie walls, floors and roofs into a connected box and to repair/strengthen damaged wall zones.

B. Documented Nepal masonry case: Shital Niwas after the 2015 earthquake

The Shital Niwas study in the STR 715 Drive collection documents that the palace was damaged in the 2015 Gorkha earthquake. After condition assessment and comparison of intervention options, steel plates and CFRP bands were selected for retrofitting. The study also identifies grouting/local reconstruction decisions according to masonry damage severity.

C. RC structures — methods supported by the STR 715 RC retrofit sources

  1. RC jacketing / section enlargement. Add reinforcement and concrete around deficient columns or other members to increase strength, stiffness and confinement.
  2. Steel jacketing. Strengthen selected columns or joints with steel plates/angles/jackets.
  3. FRP / CFRP wrapping. Improve local confinement and deformation capacity without large added mass.
  4. Add RC shear walls. Increase global lateral strength/stiffness and reduce excessive drift.
  5. Add steel bracing. Create a stronger global lateral-load-resisting system and reduce deformation demand on weak frames.
  6. Base isolation / damping where appropriate. Reduce seismic demand rather than only increasing member capacity; feasibility depends strongly on the building and retrofit objective.
  7. Strengthen deficient connections and load paths. Beam-column joints, foundations and other weak links must be checked because upgrading one member without a compatible load path can transfer failure elsewhere.
Exam sketch RC retrofit can act locally on a deficient member or globally by adding a new lateral system.

Exam-ready conclusion

Post-Gorkha retrofitting in Nepal should be described as a damage-driven and system-driven process: restore cracks and unstable masonry, tie masonry walls/floors/roofs into box action, strengthen openings and diaphragms, and upgrade RC members or the global lateral system through jacketing, FRP, shear walls or bracing as justified by assessment. The strongest Nepal-specific source in this study set is the 2016 Government guideline, while Shital Niwas provides a documented CFRP/steel-plate masonry case.

Equal displacement ruleEqual energy rule
1

How are the equal displacement and equal energy rules applied in the performance assessment of structures? Describe with the help of necessary sketches.

10 marks
1 · CompareElastic vs inelastic response
2 · Long-periodEqual displacement
3 · Short-periodEqual energy
4 · ApplyEstimate inelastic demand
Primary course sourceThe STR 715 file `peerformance points.pdf` states that the equal-displacement rule assumes nearly equal elastic and inelastic peak displacement for sufficiently long-period structures; it gives approximately T > 0.7 s. It also states that for low-period structures, approximately T < 0.3 s, the equal-energy concept is used, with gradual transition between about 0.3 s and 0.7 s.

A. Equal displacement rule

The rule states that, for a structure in the longer-period range, the maximum displacement of the inelastic system is approximately equal to the maximum displacement of the corresponding elastic system.

Δinelastic,max ≈ Δelastic,max Course-source relation for the long-period range: Rμ = μ    for approximately T > 0.70 s

Application in performance assessment: first determine the elastic spectral displacement demand. For a ductile structure in the range where the rule is applicable, that displacement can be used as an approximation of the inelastic displacement demand. The corresponding point on the capacity curve is then checked against IO / LS / CP deformation limits.

Sketch 1 Same peak displacement, but the inelastic system develops lower force and undergoes yielding.

B. Equal energy rule

For short-period structures the course source states that the energy represented by the area under the elastic response is taken approximately equal to the energy under the idealized inelastic response. The inelastic displacement therefore need not equal the elastic displacement.

Equal-energy concept: Area under elastic F–Δ response ≈ Area under inelastic F–Δ response Use in the supplied notes: approximately T < 0.30 s
Sketch 2 The governing idea is equal area/energy, not equal peak displacement.
Formula cautionThe text extraction of the supplied source contains a typographically ambiguous short-period strength–ductility expression. This answer therefore preserves the unambiguous course rule—equal areas/energy for the short-period range—instead of guessing a missing mathematical symbol.

Exam-ready comparison

Longer period: estimate inelastic displacement using the elastic displacement. Short period: estimate inelastic response by equating elastic and inelastic energy. Both rules are approximations used to translate elastic earthquake demand into expected nonlinear structural response.

Final Examination — Q2
Pushover analysisTime history analysis
2

Explain pushover analysis. Why is time history analysis considered superior to other static methods?

10 marks
1 · ModelNonlinear structure
2 · PushIncrease lateral load
3 · ReadCapacity + hinges + drift
4 · CompareStatic pushover vs time history

Pushover analysis is a nonlinear static procedure in which the structural model is subjected to gravity load and then to a monotonically increasing lateral-load pattern until a target displacement or a significant nonlinear response state is reached.

Pushover procedure

  1. Define geometry, mass, stiffness, material properties and gravity loads.
  2. Assign nonlinear properties / plastic hinges to the relevant members.
  3. Select a lateral load pattern.
  4. Apply lateral load incrementally.
  5. At each step record base shear, roof/control displacement, storey drift and hinge formation.
  6. Plot the capacity curve: base shear \(V_b\) versus roof displacement \(\Delta_r\).
  7. Use the curve to identify yield, post-yield behaviour, weak storeys, ductility and possible failure mechanism.
  8. If the capacity-spectrum method is used, convert the response to spectral coordinates and compare capacity with demand.
Pushover output Capacity curve + sequence of nonlinear response.

Why time-history analysis is superior to a static method

Static pushover

  • Uses an assumed lateral-load pattern.
  • Represents response through a sequence of static equilibrium states.
  • Provides excellent capacity/mechanism insight.
  • Does not reproduce the actual time sequence of earthquake loading.

Time-history analysis

  • Applies an accelerogram as a function of time.
  • Captures duration and frequency content.
  • Can capture repeated load reversals and nonlinear cyclic response.
  • Produces complete histories of displacement, acceleration, drift and force.
M ü(t) + C u̇(t) + R[u(t)] = − M r ag(t)

Because the equations of motion are solved step-by-step, nonlinear time-history analysis can represent effects that a single static loading pattern cannot directly reproduce, including time sequence, cyclic loading, frequency content, response reversals, residual deformation and record-to-record variability.

Source basis`Pushover1.pdf` defines pushover as nonlinear static analysis and describes the capacity-curve workflow. `seismic_assessment_final.pdf` states that time-history analysis captures nonlinear behaviour, full duration and frequency content, whereas static methods miss time-dependent response.

Balanced conclusion

Time-history analysis is considered more complete, not automatically “better in every practical situation.” It requires reliable nonlinear modelling and suitable earthquake records. Pushover remains valuable because it is simpler and clearly exposes structural capacity and failure mechanisms.

3 · JudgeIO / LS / CP
4 · IdealizeExtract yield + ductility

The performance point is the compatible intersection of the capacity spectrum and the seismic demand spectrum. It is an estimate of the expected maximum structural response at the selected earthquake demand.

Information obtained from the performance point

  • Spectral displacement, Sd — related to structural displacement demand.
  • Spectral acceleration, Sa — related to force/base-shear demand.
  • Expected roof/control displacement after conversion from the equivalent SDOF representation.
  • Expected storey drift / deformation demand to be checked against limits.
  • Performance level — whether response lies in or beyond IO, LS, CP or another adopted limit state.
  • Nonlinear state — approximate extent of post-yield response and hinge/deformation demand.
  • Adequacy of retrofit / existing structure when the predicted response is compared with the target performance objective.
Core figure The coordinates of the intersection are the principal spectral demand outputs.

Why capacity-curve idealization is necessary

  1. The raw pushover curve is nonlinear and may contain many local slope changes.
  2. A bilinear idealization reduces it to an elastic branch + post-yield branch.
  3. It gives a defined yield force and yield displacement.
  4. It provides effective stiffness, post-yield behaviour and ductility.
  5. It simplifies conversion to an equivalent SDOF / spectral representation used in performance-point calculations.
  6. The supplied course material uses the equal-energy concept so that the area under the actual and idealized force–deformation curves is kept equal when locating the significant yield point.
From the idealized capacity curve: Ke = Vy/Δy      μ = Δu/Δy
Course-source example`peerformance points.pdf` gives an example performance point in spectral coordinates and explicitly says bilinear idealization is used to judge yield displacement / yield base shear, with equal area under actual and idealized curves.

Exam-ready conclusion

The performance point tells us how much response the earthquake is expected to demand; idealization tells us where yielding begins and how much nonlinear deformation capacity is available. Together they allow performance assessment against IO / LS / CP limits.

Define fragility analysis. How are fragility curves derived empirically? Write down the detailed procedure with appropriate relationships/expressions.

10 marks
1 · ObserveReal earthquake damage
2 · ClassifyBuilding + damage states
3 · LinkDamage to intensity measure
4 · FitStatistical fragility function

Fragility analysis expresses the probability that a structure reaches or exceeds a specified damage state for a given earthquake intensity measure.

Empirical basisThe Drive paper `Derive empirical fragility functions for Nepali residential buildings.pdf` states that empirical fragility functions rely on real earthquake damage data. It derives functions from damage records for major Nepali earthquakes and treats fragility as the conditional probability of reaching/exceeding a damage state as a function of an intensity/demand parameter.

Detailed empirical derivation procedure

  1. Collect post-earthquake damage data. Record a sufficiently large building inventory from one or more earthquake events.
  2. Define homogeneous building classes. Separate RC, brick masonry, stone masonry or other typologies so unlike structural systems are not mixed indiscriminately.
  3. Define damage classes / states. Establish consistent categories such as slight, moderate, extensive and complete/collapse.
  4. Choose the intensity measure (IM). The Nepali empirical paper uses measures such as PGA and spectral acceleration.
  5. Estimate IM for each location / observation. Where measurements are sparse, the selected ground-motion model is used consistently to estimate intensity.
  6. De-aggregate / bin the database. Group buildings by typology, damage state and intensity level so the fraction exceeding each damage state can be calculated.
  7. Form empirical exceedance probabilities. For damage state \(ds\) and intensity bin \(IM_j\), estimate the proportion of buildings reaching or exceeding that state.
  8. Select and test the statistical distribution. The Nepali study tests normality of transformed data with the Anderson–Darling test and finds the lognormal model suitable for its database.
  9. Estimate lognormal parameters. Determine the median \(\mu_{ds}\) and logarithmic standard deviation / dispersion \(\zeta_{ds}\) for each damage state.
  10. Construct the fragility function. Evaluate the cumulative probability over the required intensity range and plot one curve for each damage state.
  11. Validate / compare. Compare the fitted curves with observed damage trends and recognize that empirical functions are strongly dependent on region, building class and data quality.
Empirical lognormal fragility relationship: FD(ds) = Φ [ ( ln D − ln μds ) / ζds ] where: FD(ds) = conditional probability of damage state ds or greater D = demand / intensity parameter μds = median parameter for damage state ds ζds = logarithmic standard deviation Φ = standard normal cumulative distribution function
Interpretation For any selected IM, move vertically to a damage-state curve and read the probability of exceedance.
Empirical ≠ analyticalDo not describe an empirical fragility curve as if it came primarily from a finite-element pushover/IDA model. In the supplied Nepali empirical paper, the defining input is observed earthquake damage statistics; modelling may support IM estimation, but the damage evidence is empirical.

Exam-ready conclusion

Empirical fragility derivation converts a real post-earthquake database into probabilistic damage functions by consistently classifying buildings/damage, assigning earthquake intensity, calculating exceedance proportions and fitting a validated statistical distribution.

What types of information can be obtained from non-destructive testing (NDT)? Explain any two NDT methods with necessary sketches.

10 marks
1 · PurposeAssess without major damage
2 · InformationStrength + defects + reinforcement
3 · Method 1Rebound hammer
4 · Method 2UPV

Non-destructive testing (NDT) evaluates material or structural condition while causing little or no permanent damage to the member being investigated.

Information obtainable from NDT

  • Concrete surface hardness / indicative compressive strength through calibrated correlations.
  • Uniformity and quality of concrete.
  • Internal defects such as cracks, voids, honeycombing or discontinuities.
  • Reinforcement information such as location and cover depth when the appropriate locating instrument is used.
  • Corrosion-related condition when electrochemical NDT techniques are used.
  • Comparative condition of different zones to identify areas needing cores, opening-up or detailed repair.

Method 1 — Rebound hammer

Principle: a spring-driven mass impacts the concrete surface. The rebound of the mass is measured as a rebound number/index. A calibration relationship is then used to estimate or compare surface hardness and indicative concrete strength.

Rebound hammer Fast and portable; mainly reflects near-surface hardness, so surface condition affects interpretation.

Method 2 — Ultrasonic Pulse Velocity (UPV)

Principle: a transmitter sends an ultrasonic pulse through the concrete and a receiver measures the travel time. If the travel path length is \(L\) and travel time is \(t\), pulse velocity is:

V = L / t

Higher, consistent velocity generally indicates denser and more continuous concrete; unusually low or locally reduced velocity can indicate poor quality or defects. UPV is particularly useful for uniformity assessment and detecting internal discontinuities.

UPV Pulse transmission through the member provides information about internal continuity and relative concrete quality.
FeatureRebound hammerUPV

Best useRapid surface hardness / comparative strength indicationUniformity + internal continuity / defect indication
Main cautionSurface condition and carbonation influence resultMoisture, path geometry, coupling and reinforcement can influence readings
Source basis`seismic_assessment_final.pdf` explicitly identifies rebound hammer and UPV as the two NDT methods, and lists material strength, internal defects, reinforcement details and corrosion condition among information obtainable from NDT.

Exam-ready conclusion

No single NDT method gives a complete structural diagnosis. A reliable assessment combines test results, visual inspection and—where necessary—targeted destructive verification such as cores. Rebound hammer and UPV are complementary because one is predominantly a surface-hardness indicator while the other probes wave transmission through the member.

Define structural health monitoring (SHM). Describe the detailed procedure for the seismic assessment of historical structures using sensors.

10 marks
1 · BaselineDocument existing condition
2 · InstrumentPlace sensors
3 · ExtractModal features
4 · CompareDetect change / damage

Structural Health Monitoring (SHM) is the process of implementing a damage-detection and damage-characterization strategy for an engineering structure. The supplied SHM notes organize the process around health monitoring, operational evaluation, data-feature extraction and statistical/model development.

Source anchor`SHM.pdf` defines SHM this way and states that damage may alter displacement, acceleration, strain, natural frequencies, mode shapes, damping and modal strain energy. It also lists accelerometers, displacement sensors, seismometers and strain gauges among available sensors.

Procedure for a historical structure

  1. Historical/structural documentation. Record geometry, construction materials, previous alterations, visible cracks, wall/floor connections and known earthquake damage.
  2. Establish baseline condition. Perform visual inspection and, where justified, non-destructive evaluation so pre-existing defects are known before interpreting sensor data.
  3. Define monitoring objectives. Decide whether the goal is to detect damage existence, locate it, quantify severity, assess post-earthquake integrity, or update a structural model.
  4. Select measurable response quantities. Choose acceleration, displacement, velocity and/or strain according to the monitoring objective.
  5. Plan sensor locations. Place sensors at floors, roofs, major wall lines or other strategic locations so global modes and critical local response can be observed.
  6. Acquire baseline vibration data. Record ambient/forced vibration or other controlled measurements before a damaging event.
  7. Process the records. Filter noise, transform time histories where needed, and identify natural frequencies, mode shapes and damping.
  8. Compare measured features with the baseline. Significant changes in stiffness-sensitive quantities—especially modal properties—may indicate damage.
  9. Update/validate the structural model. The supplied SHM notes describe finite-element model updating by adjusting structural parameters until measured and analytical modal properties agree sufficiently.
  10. Post-earthquake reassessment. Repeat measurements after an earthquake and compare with the baseline; combine sensor results with visual/NDT evidence before making a safety or retrofit decision.
Memory chain Structure → Sensors → DAQ/DSP → modal features → baseline comparison → damage decision.
Historical-structure cautionThe supplied SHM file is a general SHM source; it does not prescribe a heritage-specific sensor layout. Therefore exact sensor counts, spacing or attachment methods are not invented here.

Exam-ready conclusion

For a historical structure, sensor-based seismic assessment should be used as a non-destructive evidence chain: document the structure, establish a baseline, instrument it, extract response features, compare pre-/post-event behaviour, update the model, and combine the result with inspection before intervention.

As a structural engineer, how would you assess the vulnerability of reinforced concrete structures located in Pokhara Valley?

Pokhara-specific sourceThe Drive thesis proposal `Seismic Vulnerability Assessment and Retrofitting Strategies for Non-Engineered RC Buildings in Pokhara Metropolitan City` explicitly proposes field survey, typology classification, ETABS/SAP2000 modelling, modal analysis, pushover analysis, selective time-history checks and comparison of retrofit alternatives.

Assessment workflow

  1. Define the study area and building inventory. Classify representative low-/medium-rise RC building typologies, age, storeys, occupancy, structural system and apparent construction quality.
  2. Collect field and municipal information. Obtain drawings where available; otherwise measure geometry and record column sizes, beam sizes, infill arrangement, openings and visible irregularities.
  3. Record Pokhara-relevant deficiencies. The supplied proposal highlights soft storeys, poor seismic detailing, inadequate column/joint shear capacity, undersized columns and structural irregularities as important vulnerabilities in non-engineered RC stock.
  4. Include site/soil information. Classify the site using available geological/geotechnical information because Pokhara’s urban/geotechnical context is explicitly part of the local assessment problem.
  5. Carry out rapid visual screening. Note soft storey, torsional irregularity, short/captive columns, pounding potential, poor construction and deterioration.
  6. Obtain material/property information. Use available records and NDT/field evidence to reduce uncertainty in concrete strength, reinforcement and deterioration.
  7. Create analytical models. Build representative 3-D models in ETABS/SAP2000 or equivalent.
  8. Run modal analysis. Obtain periods and mode shapes and identify irregular dynamic behaviour.
  9. Run nonlinear static pushover. Obtain capacity curves, performance point, target displacement, drift and probable hinge/failure mechanisms.
  10. Use selective nonlinear dynamic checks for critical cases. Time-history or IDA-type checks can be used when the static method is insufficient for a critical typology.
  11. Quantify vulnerability. Compare base-shear capacity, displacement capacity, ductility, inter-storey drift, damage indices and—where developed—fragility probabilities.
  12. Prioritize retrofit. Select local/global interventions according to the controlling deficiency and verify the retrofitted model.
Pokhara workflow Do not jump straight to software; vulnerability begins with typology, site and observed deficiency.
Scope cautionThe Pokhara thesis proposal is a proposed methodology, not a completed citywide vulnerability database. Therefore this answer uses it as a procedure source, not as proof of final vulnerability results for all Pokhara RC buildings.

Final Examination — Q9
Nepal masonry vulnerabilityHeritage retrofit
9

Why are most masonry structures in Nepal vulnerable during earthquakes? Describe the retrofitting methods used for heritage structures.

10 marks

Why Nepal masonry is vulnerable

  • Unreinforced or lightly tied walls → brittle behaviour.
  • Mud / weak mortar → low tensile and bond capacity.
  • Poor wall-to-wall and wall-to-floor/roof connections → loss of box action.
  • Flexible timber floors/roofs may not distribute lateral forces effectively.
  • Heavy walls and roofs increase seismic inertia.
  • Large/irregular openings and plan irregularity create stress concentration.
  • Out-of-plane wall failure and corner separation are common critical mechanisms.

Heritage-retrofit principle

  • Preserve historic fabric.
  • Use compatible materials.
  • Prefer minimum necessary intervention.
  • Strengthen connections and load path.
  • Where possible, use reversible or less intrusive measures.
Nepal evidenceThe Government of Nepal retrofitting guideline identifies out-of-plane wall damage, in-plane shear cracking, corner damage, cracks at openings and weak wall intersections, and prescribes wall bands, vertical reinforcement, wall jacketing, diaphragm strengthening, through-elements and grouting. The Shital Niwas case identifies low-strength mud mortar, heavy walls/floors, long unsupported walls, flexible diaphragms, high opening ratio and missing earthquake-resistant features as major vulnerabilities.

Heritage-compatible retrofit methods in the supplied study set

  1. Crack grouting / compatible repointing. Restore continuity in cracked masonry without unnecessary reconstruction.
  2. Steel ties / bands. Tie perpendicular walls and connect wall lines at floor/roof levels to reduce separation.
  3. Timber ring beams / diaphragm improvement. Improve wall-to-floor/roof integration using material compatible with traditional construction where appropriate.
  4. Vertical ties / prestressing-type rods. Improve wall integrity and compression/tie action when justified by assessment.
  5. Wall jacketing or mesh-based strengthening. The Nepal guideline includes external mesh/band systems for low-strength masonry; selection depends on the heritage value of finishes and reversibility constraints.
  6. Local reconstruction of unstable masonry. Where cracking/crushing is too severe for repair, carefully dismantle and rebuild the unsafe zone using compatible material.
  7. Specialized local strengthening. The documented Shital Niwas intervention selected steel plates and CFRP bands after condition assessment and structural analysis.
Core idea Heritage retrofit aims to create box action and restore continuity without unnecessarily destroying historic fabric.

Exam-ready conclusion

Nepal masonry is vulnerable mainly because earthquake loads demand tension, shear, diaphragm action and interconnection from systems built primarily for gravity compression. Heritage retrofit therefore focuses on restoring continuity, tying walls/floors/roofs together and strengthening critical zones with compatible, minimally intrusive measures.

Recommended final technical-report structure

  1. Executive summary. Existing condition, principal deficiencies, selected retrofit, target performance and key recommendation.
  2. Building description. Location, age, occupancy, hospital functions, structural system, number of storeys, construction history, alterations and available drawings.
  3. Site and seismic investigation. Kathmandu site information, soil/geotechnical data available to the project, adopted earthquake hazard and applicable design/evaluation basis.
  4. Condition survey and testing. Visual damage map, crack/deterioration record, material tests/NDT, reinforcement verification where available, and photographs.
  5. Existing structural model. Modelling assumptions, member properties, load path, mass/stiffness representation and uncertainty statement.
  6. Seismic assessment results. Modal response, DCR or component checks where applicable, pushover/time-history results, drift, hinge state, capacity/demand and identified failure mechanisms.
  7. Performance objective. State the target level clearly. In the supplied course note, the hospital target is IO because post-earthquake functionality is critical.
  8. Retrofit alternatives. Compare feasible local/global options such as member jacketing, FRP, shear walls, bracing or other justified interventions.
  9. Selected retrofit design. Give design basis, member details, connections, foundations affected, drawings, construction sequence and specifications.
  10. Non-structural/functional considerations. Record the items that can prevent hospital operation even if the main structure survives—equipment anchorage, partitions, ceilings, services and access—where assessed in the project.
  11. Cost and implementation. BOQ, indicative cost, phasing, temporary works, hospital downtime/continuity constraints and construction schedule.
  12. Post-retrofit verification. Reanalyse the retrofitted model and demonstrate improvement in capacity, drift and target performance.
  13. QA/QC and monitoring. Material acceptance, site inspection hold points, as-built records and, where appropriate, post-retrofit monitoring.
  14. Conclusions and limitations. State what is proven, what remains uncertain, and any restrictions on occupancy or future modification.
Report logic A hospital retrofit report must connect evidence → performance gap → intervention → verified post-retrofit performance.

Exam-ready conclusion

The final report should be auditable: every retrofit recommendation must trace back to an observed or analytical deficiency, and every claimed improvement must be demonstrated by post-retrofit analysis, drawings/specifications and implementation/QA requirements.
